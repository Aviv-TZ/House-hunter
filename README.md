# 🏠 House Hunter

סוכן שסורק מודעות להשכרה ב**יד 2**, ב**קבוצות פייסבוק** וב-**Marketplace**, מאחד כפילויות (אותה דירה שפורסמה
בכמה מקומות), מסנן לפי הקריטריונים שלך, שולח התראה לטלגרם על כל דירה חדשה שמתאימה,
ומנהל דאשבורד של מה ראית ועם מי יצרת קשר.

## מה הוא עושה
1. **סורק** את יד 2 (תל אביב, גבעתיים, רמת גן · עד 7,500 ₪ · 3 חדרים ומעלה) - כל שעה.
2. **פותח לעומק** כל מודעה חדשה שעברה סינון ראשוני (קומה, מעלית, חניה, תיווך, תיאור).
3. **מנתח** לפי הכללים ב-`config.yaml`:
   | כלל | התנהגות |
   |---|---|
   | מעל קומה 1 בלי מעלית | ❌ נפסל · לא ידוע → 🟡 לבירור |
   | חיות מחמד | "לא" מפורש → ❌ · לא צוין → 🟡 "לבקש אישור" |
   | מטבח | "קטן / מטבחון" → ❌ · לא צוין → 🟡 "לבקש תמונה" |
   | תיווך | מעל 6,800 ₪ → ❌ · עד 6,800 → 🟡 מסומן |
   | סאבלט / שותפים / החלפת דירות | ❌ |
   | מחיר מתחת ל-4,000 ₪ | 🟡 "מחיר חשוד" |
   | שכונות מועדפות (מרום נווה, שיכון ותיקים, נגבה, שיכון מזרחי) | ⭐ ציון גבוה, נבדקות ראשונות |
   | חניה פרטית / "חניה בשפע ברחוב" | 🚗 בונוס גדול בציון (+12 / +6) |
   | פוסט של מחפשי דירה / מכירה / סאבלט | ❌ (Claude מזהה) |
4. אם יש מפתח של Claude - **Claude קורא את טקסט המודעה** ומשלים מה שמילות מפתח לא תופסות
   (חיות, גודל מטבח, דמי תיווך, דגלים אדומים) + כותב תקציר של שורה.
5. **מאחד כפילויות** - אותה דירה ביד 2, ב-10 קבוצות וב-Marketplace = כרטיס אחד עם קישורים לכל הפרסומים.
   מזהה לפי: טקסט זהה (פוסט שהועתק לכמה קבוצות - בלי לבזבז קריאה ל-Claude), אותו טלפון, טקסט כמעט זהה,
   או אותו רחוב + חדרים + מחיר דומה + מספר בית/קומה תואמים.
6. **מתריע בטלגרם** (✅ התאמה מלאה / 🟡 דורש בירור) כולל תמונה, וגם על **ירידות מחיר**.
7. **דאשבורד** (Streamlit): סינון, סטטוס לכל מודעה (חדש / ראיתי / מעניין / יצרתי קשר / קבעתי צפייה / ראיתי בפועל / לא רלוונטי) והערות.


### טלגרם (2 דקות)
1. בטלגרם פתח את **@BotFather** ← `/newbot` ← קבל token ← הדבק ב-`TELEGRAM_BOT_TOKEN`.
2. שלח הודעה כלשהי לבוט החדש שלך.
3. פתח בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` ← העתק את `chat.id` ל-`TELEGRAM_CHAT_ID`.

בלי טלגרם - ההתראות פשוט מודפסות למסך.

### Claude (לא חובה)
מפתח מ-[console.anthropic.com](https://console.anthropic.com) ל-`ANTHROPIC_API_KEY`.
ברירת המחדל היא `claude-opus-5-5` (הכי מדויק, בערך סנט אחד למודעה). עם עשרות קבוצות פייסבוק זה יכול להגיע
לכמה מאות פוסטים חדשים ביום (פוסטים כפולים לא נשלחים ל-Claude), כלומר בערך 1-3 דולר ליום.
אפשר להחליף ב-`config.yaml` ל-`claude-haiku-5-5` - זול פי ~40 ומספיק טוב לחילוץ פרטים ממודעה.
בלי מפתח - הסוכן עובד עם כללים ומילות מפתח בלבד (יותר מודעות יסומנו "לבירור").

## הרצה
```bash
python -m hunter scan        # סריקה אחת (יד 2 + פייסבוק אם הגיע זמנו)
python -m hunter scan --only facebook   # רק מקור אחד
python -m hunter loop        # סריקה כל שעה (every_minutes ב-config) - להשאיר פתוח
streamlit run dashboard.py   # דאשבורד: http://localhost:8501
```

**ריצה ראשונה:** הסוכן לא מציף אותך במאות מודעות קיימות. הוא אוסף אותן בשקט (60 לעומק בכל ריצה,
כדי לא להעמיס על יד 2), ושולח הודעת סיכום כשסיים. משם והלאה - רק מודעות חדשות. כל המודעות הקיימות זמינות בדאשבורד.

### פייסבוק (קבוצות + Marketplace)
הסוכן פותח דפדפן Chromium עם **פרופיל נפרד** (בתיקייה `data/fb_profile`, לא הדפדפן הרגיל שלך), מחובר לחשבון שלך,
וקורא את הקבוצות ואת Marketplace כמו שאתה היית קורא - לאט, מעט עמודים בכל ריצה.

```bash
pip install -r requirements.txt
playwright install chromium          # פעם אחת
python -m hunter fb-login            # נפתח חלון - התחבר לפייסבוק כרגיל, ואז Enter בטרמינל
python -m hunter fb-groups           # שומר את רשימת הקבוצות שלך ל-data/fb_groups.yaml
```
1. פתח את `data/fb_groups.yaml` - קבוצות ששמן נראה קשור לדירות מסומנות `enabled: true`. תקן לפי הצורך.
2. **Marketplace**: בדפדפן, Marketplace ← נכסים להשכרה ← קבע מיקום (רמת גן / תל אביב), רדיוס, מחיר עד 7,500
   ו-2+ חדרי שינה (= 3 חדרים) ← העתק את הכתובת ל-`marketplace_urls` ב-`config.yaml`.
3. ב-`config.yaml` שנה `facebook: enabled: true`.
4. ריצת בדיקה עם חלון גלוי: `python -m hunter scan --only facebook --show-browser --debug`
   (צילומי מסך ו-HTML נשמרים ב-`data/fb_debug` - אם משהו לא נקרא נכון, אלה הקבצים שצריך כדי לתקן).

**בפייסבוק Claude הכרחי** - פוסטים הם טקסט חופשי, ו-Claude מחלץ מהם מחיר, חדרים, כתובת, קומה, טלפון ומזהה
אם זה בכלל הצעת השכרה (ולא "מחפשים דירה").

**מגבלות וסיכון - חשוב:**
- פייסבוק אוסרת איסוף אוטומטי, וחשבונות שמזוהים כאוטומטיים עלולים לקבל הגבלה זמנית. ההגדרות כאן שמרניות:
  כל שעתיים, 10 קבוצות בכל ריצה ברוטציה, 15-45 שניות בין עמודים, 15 פריטי Marketplace לריצה.
  אל תוריד אותן משמעותית.
- אין כאן שום עקיפה של מנגנוני הגנה. אם פייסבוק מבקשת להתחבר מחדש או אימות - הסריקה עוצרת ותקבל הודעה
  להריץ `fb-login`.
- פייסבוק משנה את מבנה הדף לעתים קרובות. הקוד קורא מבנה כללי (פוסטים וקישורים קבועים), אבל ייתכן שיידרש כוונון
  אחרי הריצה הראשונה - בשביל זה `--debug`.

### תזמון אוטומטי (במקום להשאיר `loop` פתוח)
- **Mac/Linux** - `crontab -e`:
  `7 * * * * cd /path/to/House-hunter && .venv/bin/python -m hunter scan >> data/cron.log 2>&1`
- **Windows** - Task Scheduler ← Create Basic Task ← Daily, חזרה כל שעה ←
  Program: `C:\path\House-hunter\.venv\Scripts\python.exe`, Arguments: `-m hunter scan`, Start in: `C:\path\House-hunter`.

## שינוי קריטריונים
הכל ב-`config.yaml`: ערים, מחיר, חדרים, סף תיווך, שכונות מועדפות (מזהי שכונה של יד 2), תדירות.

## מבנה
```
hunter/yad2.py     # מקור יד 2 (ה-JSON שהאתר עצמו משתמש בו), השהיות אקראיות, עצירה מנומסת אם נחסמים
hunter/rules.py    # כללי ההתאמה + זיהוי מילות מפתח בעברית
hunter/facebook.py # קבוצות + Marketplace דרך דפדפן מחובר (Playwright)
hunter/dedup.py    # איחוד כפילויות בין מקורות
hunter/llm.py      # חילוץ פרטים מטקסט חופשי עם Claude (structured output)
hunter/db.py       # SQLite: מודעות, היסטוריית מחיר, סטטוסים והערות
hunter/notify.py   # טלגרם
hunter/scan.py     # הצינור: פיד ← פרטים ← ניתוח ← התראות
dashboard.py       # Streamlit
```

## מה הלאה
- **זיהוי כפילויות לפי תמונות** (hash של תמונה) - יתפוס גם פרסומים עם טקסט וכתובת שונים.
- **מדל"ן / הומלס**: הומלס מאחורי Cloudflare; מדל"ן - לבדוק.
- **שיפור השכונות המועדפות**: הוספת שכונות ע"פ מזהה (רואים אותו ב-`data` בדאשבורד).
