# 🏠 House Hunter

סוכן שסורק מודעות להשכרה ביד 2, מסנן לפי הקריטריונים שלך, שולח התראה לטלגרם על כל מודעה חדשה שמתאימה,
ומנהל דאשבורד של מה ראית ועם מי יצרת קשר.

## מה הוא עושה
1. **סורק** את יד 2 (תל אביב, גבעתיים, רמת גן · עד 7,500 ₪ · 3 חדרים ומעלה) - כל שעה.
2. **פותח לעומק** כל מודעה חדשה שעברה סינון ראשוני (קומה, מעלית, חניה, תיווך, תיאור).
3. **מנתח** לפי הכללים ב-`config.yaml`:
   | כלל | התנהגות |
   |---|---|
   | מעל קומה 1 בלי מעלית | ❌ נפסל · לא ידוע → 🟡 לבירור |
   | חיות מחמד | "לא" מפורש → ❌ · לא צוין → 🟡 "לבקש אישור" |
   | מטבח | "קטן / מטבחון" → ❌ · לא צוין → 🟡 "לבקש תמונה" |
   | תיווך | מעל 6,800 ₪ → ❌ · עד 6,800 → 🟡 מסומן |
   | סאבלט / שותפים / החלפת דירות | ❌ |
   | מחיר מתחת ל-4,000 ₪ | 🟡 "מחיר חשוד" |
   | שכונות מועדפות (מרום נווה, שיכון ותיקים, נגבה, שיכון מזרחי) | ⭐ ציון גבוה, נבדקות ראשונות |
4. אם יש מפתח של Claude - **Claude קורא את טקסט המודעה** ומשלים מה שמילות מפתח לא תופסות
   (חיות, גודל מטבח, דמי תיווך, דגלים אדומים) + כותב תקציר של שורה.
5. **מתריע בטלגרם** (✅ התאמה מלאה / 🟡 דורש בירור) כולל תמונה, וגם על **ירידות מחיר**.
6. **דאשבורד** (Streamlit): סינון, סטטוס לכל מודעה (חדש / ראיתי / מעניין / יצרתי קשר / קבעתי צפייה / ראיתי בפועל / לא רלוונטי) והערות.

## התקנה (על המחשב שלך)
> מומלץ להריץ מהמחשב בבית. יד 2 חוסמת מהר כתובות של שרתי ענן (נבדק - שרת ענן נחסם אחרי 2-3 בקשות).

```bash
git clone https://github.com/Aviv-TZ/House-hunter.git
cd House-hunter
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # ומלא את הערכים (הסבר בהמשך)
python -m pytest -q              # בדיקה שהכל תקין
```

### טלגרם (2 דקות)
1. בטלגרם פתח את **@BotFather** ← `/newbot` ← קבל token ← הדבק ב-`TELEGRAM_BOT_TOKEN`.
2. שלח הודעה כלשהי לבוט החדש שלך.
3. פתח בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` ← העתק את `chat.id` ל-`TELEGRAM_CHAT_ID`.

בלי טלגרם - ההתראות פשוט מודפסות למסך.

### Claude (לא חובה)
מפתח מ-[console.anthropic.com](https://console.anthropic.com) ל-`ANTHROPIC_API_KEY`.
ברירת המחדל היא `claude-opus-5-5` (הכי מדויק, בערך סנט אחד למודעה).
אפשר להחליף ב-`config.yaml` ל-`claude-haiku-5-5` - זול פי ~40 ומספיק טוב לחילוץ פרטים ממודעה.
בלי מפתח - הסוכן עובד עם כללים ומילות מפתח בלבד (יותר מודעות יסומנו "לבירור").

## הרצה
```bash
python -m hunter scan        # סריקה אחת
python -m hunter loop        # סריקה כל שעה (every_minutes ב-config) - להשאיר פתוח
streamlit run dashboard.py   # דאשבורד: http://localhost:8501
```

**ריצה ראשונה:** הסוכן לא מציף אותך במאות מודעות קיימות. הוא אוסף אותן בשקט (60 לעומק בכל ריצה,
כדי לא להעמיס על יד 2), ושולח הודעת סיכום כשסיים. משם והלאה - רק מודעות חדשות. כל המודעות הקיימות זמינות בדאשבורד.

### תזמון אוטומטי (במקום להשאיר `loop` פתוח)
- **Mac/Linux** - `crontab -e`:
  `7 * * * * cd /path/to/House-hunter && .venv/bin/python -m hunter scan >> data/cron.log 2>&1`
- **Windows** - Task Scheduler ← Create Basic Task ← Daily, חזרה כל שעה ←
  Program: `C:\path\House-hunter\.venv\Scripts\python.exe`, Arguments: `-m hunter scan`, Start in: `C:\path\House-hunter`.

## שינוי קריטריונים
הכל ב-`config.yaml`: ערים, מחיר, חדרים, סף תיווך, שכונות מועדפות (מזהי שכונה של יד 2), תדירות.

## מבנה
```
hunter/yad2.py     # מקור יד 2 (ה-JSON שהאתר עצמו משתמש בו), השהיות אקראיות, עצירה מנומסת אם נחסמים
hunter/rules.py    # כללי ההתאמה + זיהוי מילות מפתח בעברית
hunter/llm.py      # ניתוח טקסט חופשי עם Claude (structured output)
hunter/db.py       # SQLite: מודעות, היסטוריית מחיר, סטטוסים והערות
hunter/notify.py   # טלגרם
hunter/scan.py     # הצינור: פיד ← פרטים ← ניתוח ← התראות
dashboard.py       # Streamlit
```

## מה הלאה
- **פייסבוק**: לא סורקים ישירות (פייסבוק חוסמת חשבונות). הכיוון: להפעיל התראות מקבוצות הדירות למייל,
  והסוכן יקרא את המיילים ו-Claude ינתח את הפוסטים.
- **מדל"ן / הומלס**: הומלס מאחורי Cloudflare; מדל"ן - לבדוק.
- **שיפור השכונות המועדפות**: הוספת שכונות ע"פ מזהה (רואים אותו ב-`data` בדאשבורד).
